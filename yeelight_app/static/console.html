Прямые команды сервера

Командная строка

Полный доступ ко всем командам: поиск ламп, добавление адреса, питание, цвет и температура.

К лампам

Нужен API-токен

Введите YEELIGHT_API_TOKEN из .env — он сохранится во вкладке и будет доступен на всех страницах.

Токен нужен, чтобы сервер отличал ваши запросы от чужих. Он не покидает эту вкладку браузера.

Ввод и вывод

Команды: discover, add, brightness, color, temp.

Быстро:

Справочник команд

Нажмите на строку, чтобы подставить команду в поле ввода.

КомандаДействие
discoverНайти лампы в сети по SSDP и добавить найденные
listПоказать сохранённый список ламп
add 192.168.1.45Добавить лампу по адресу
remove 192.168.1.45Убрать лампу из списка
on <IP> / off <IP>Включить / выключить
toggle <IP>Переключить питание
status <IP>Прочитать питание, яркость, цвет, температуру
brightness <IP> 60Яркость 1–100 %
color <IP> #33aaffЦвет шестьюнадцатеричным кодом
color <IP> 255 136 0Цвет каналами RGB 0–255
temp <IP> 4000Температура цвета 1700–6500 K

Список ламп хранится в data/bulbs.json, режимы — в data/modes.json. Оба файла переживают перезапуск сервера.
