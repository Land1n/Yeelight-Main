Архитектура

Единственная реализация операций с лампами — в yeelight-logic.

ПакетГде работаетОтветственность
yeelight-logicвездеLAN-команды, discovery, controller, miIO provisioning, типизированный dispatcher.
yeelight-managerрядом с лампамиWebSocket-клиент к серверу, локальный API и Flet-интерфейс, Wi-Fi/LAN Control.
yeelight-serverтам, где нужен веб-доступПользователи, сессии, SQLite, менеджеры, команды, режимы, веб-интерфейс.

Браузер не общается с лампами. Сервер не общается с лампами. Только менеджер выполняет операции в своей локальной сети и возвращает результат по исходящему WebSocket.

Быстрый старт

Windows-скрипты и ручные команды.

  1. Запустите tools\setup.bat: создаётся .venv, устанавливаются три пакета, генерируется .env с паролем администратора.
  2. Запустите start-server.bat и откройте http://127.0.0.1:8000.
  3. Войдите под пользователем из YEELIGHT_SERVER_ADMIN_USER и паролем из .env.
  4. На странице «Менеджеры» создайте одноразовый код.
  5. На машине с лампами выполните start-manager.bat --pair КОД, затем start-manager.bat.
  6. Нажмите «Найти лампы» и добавьте нужные адреса.
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e packages\yeelight-logic
.\.venv\Scripts\python.exe -m pip install -e packages\yeelight-manager
.\.venv\Scripts\python.exe -m pip install -e packages\yeelight-server
.\.venv\Scripts\python.exe -m yeelight_server

Спаривание

Токен менеджера выдаётся один раз и хранится локально в защищённом виде.

1. Пользователь создаёт код на странице «Менеджеры».
2. Менеджер отправляет код, имя и версию на POST /api/v1/managers/pair.
3. Сервер проверяет срок и одноразовость, создаёт токен ylm_… и сохраняет только хеш.
4. Менеджер сохраняет токен: DPAPI на Windows, файл 0600 на Unix.
5. Менеджер подключается к /api/v1/managers/ws с заголовком Authorization: Bearer.

Wi-Fi и LAN Control

Только локально, только после подтверждения.

Менеджер проверяет, что запрос пришёл с loopback, и требует confirm: true. Пароль Wi-Fi не записывается в файлы и не логируется. Поддерживается модель yeelink.light.color1; для остальных используйте официальное приложение.

Ответ miIO означает «запрос доставлен», но не доказывает подключение к сети или включение LAN Control. Проверяйте лампу отдельно через discovery и статус.

Проверки

Обычные тесты не требуют ламп и сети.

.\.venv\Scripts\python.exe -m unittest discover -s tests -v

Аппаратные тесты включаются только переменными окружения, см. tests/README.md. Они не запускаются по умолчанию.

Частые проблемы

Что проверить в первую очередь.

Менеджер не подключается

Проверьте адрес сервера, срок действия токена и что исходящий WebSocket не блокируется. В логах сервера есть событие manager_connected без секретов.

Команда вернула manager_unavailable

Менеджер не был подключён в момент доставки. Сервер не выдаёт такую команду за выполненную. Запустите менеджер и повторите действие.

Лампа не находится

Компьютер с менеджером должен быть в той же сети, что и лампа. Проверьте LAN Control, multicast/SSDP и TCP 55443. При необходимости добавьте IP вручную.

Режим остановился с ошибкой

После десяти ошибок подряд цикл завершается и сохраняет last_error. Проверьте питание лампы, IP и лимит LAN-команд (примерно 60 в минуту).
