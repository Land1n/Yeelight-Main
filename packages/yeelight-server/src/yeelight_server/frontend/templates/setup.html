Wi-Fi и LAN Control — только локально

        
Эти операции намеренно отсутствуют в API сервера.

      

    

    локально
  

  

    

      Настройка Wi-Fi и включение LAN Control выполняются в окне менеджера или через его
      локальный API на 127.0.0.1. Пароль Wi-Fi передаётся только в памяти,
      не сохраняется и не попадает в ответы. Требуется отдельная галочка подтверждения.
    

    

      Сервер не маршрутизирует эти действия и не принимает пароль Wi-Fi. Если менеджер
      находится на другой машине, его локальный API остаётся недоступен из сети.

Безопасность

        
Коротко о модели доступа.

      

    

  

  
    
    
  • Пароль человека хранится как scrypt-хеш; сессия — непрозрачная cookie HttpOnly, изменения защищены CSRF-заголовком.
    • 
    
  • Токен менеджера хранится на сервере только как SHA-256 хеш и передаётся один раз при спаривании.
    • 
    
  • Менеджер хранит токен через DPAPI (Windows) или файл с правами 0600 (Linux/macOS).
    • 
    
  • Для доступа из LAN используйте HTTPS через reverse proxy; cookie помечается Secure при TLS.
